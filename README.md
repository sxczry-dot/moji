# 默记 (Moji)

原生安卓自动记账 App（Kotlin）。监听银行短信和支付 App 通知，自动识别收支、归类、入账，无需手动记一笔。

## 功能

- 自动抓取：监听银行短信（95588/95533 等各大银行）与支付 App 通知，解析金额、商户、收支方向
- 智能分类：内置商户关键词库，自动归入餐饮、交通、购物、娱乐等类别，也支持手动改
- 智能过滤：自动跳过验证码、理财申购/赎回、零钱通/余额宝类资金调度短信，不误记
- 去重：同一条消费多渠道通知只记一次
- 周期账单：支持房租、订阅等按月/按季度自动重复入账
- 统计图表：月度收支汇总、分类占比图
- 本地数据：Room 数据库全部存本机，可导出 CSV
- 隐私保护：无联网权限，数据不出手机；App 锁（PIN）防他人查看

## 技术栈

- Kotlin + Jetpack Compose
- Room 数据库
- NotificationListenerService + SMS Receiver 后台监听
- 正则规则解析 + 关键词分类器

## 权限说明

- 短信读取：解析银行交易短信
- 通知使用权：解析微信/支付宝支付通知
- 以上权限仅在本机解析记账，不上传任何数据

## 构建

1. Android Studio（SDK 35+）打开本项目 → Gradle 同步
2. 连接 Android 8.0+ 真机 → Run
3. 首次启动按引导开启短信/通知权限

自用项目，不上架应用商店。
